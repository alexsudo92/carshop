# AutoMarket Studio

Статическая версия автосалона на чистых HTML, CSS и JavaScript с jQuery.

## Структура

- `pages/` — отдельные HTML-страницы приложения.
- `css/style.css` — общие стили без Tailwind и фреймворков.
- `js/jquery.min.js` — локальная копия jQuery.
- `js/data.js` — данные автомобилей и стартовый пользователь.
- `js/app.js` — логика авторизации, каталога, конфигуратора, профиля и оформления заявки.
- `data/images/` — изображения автомобилей.

## Запуск

```bash
npm run dev
```

Откройте `http://localhost:3000/pages/login.html`.

Тестовый пользователь:

- логин: `admin`
- пароль: `admin`

Данные пользователей и сессия сохраняются в `localStorage` браузера.
