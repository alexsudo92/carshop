# AutoMarket Studio

Статический сайт автосалона, переписанный на чистые HTML, CSS и JavaScript с использованием jQuery. Next.js, React, TypeScript и Tailwind больше не используются.

## Структура

- `pages/` — отдельные HTML-страницы приложения: вход, регистрация, каталог, конфигуратор, профиль, оформление заказа, информационные страницы.
- `css/` — общие стили интерфейса.
- `js/` — локальная копия jQuery и клиентская логика сайта.
- `data/` — исходные данные каталога, пользователей и изображения автомобилей.

## Запуск

```bash
npm start
```

После запуска откройте http://localhost:3000. Корневая страница перенаправляет пользователя на вход или в каталог.

## Проверка

```bash
npm run check
```

Команда проверяет наличие обязательных статических файлов, подключение jQuery/app.js и отсутствие ключевых артефактов Next.js.
